# JS-Art — оверлей-редактор стилей в реальном времени

Дата: 2026-10-06 · Статус: согласован дизайн, ждёт ревью спецификации

## Цель

Инструмент арт-разработчика: папка `js-art/`, которая кладётся в любой статический проект и даёт поверх сайта
панель с ползунками для правки цветов, типографики, отступов и размеров в реальном времени. Результат
сохраняется прямо в файлы проекта — код руками не правится.

Критерии успеха:

- запуск одной командой, без `npm install` и сборки;
- любое изменение видно на сайте мгновенно;
- у каждого контрола есть исходное (дефолтное) значение и сброс к нему;
- «Сохранить» записывает CSS в проект, и после деплоя (`docker compose up --build`) прод выглядит так же;
- панель не попадает в прод и не конфликтует со стилями сайта;
- работает на телефоне (ширина 375 px) и на десктопе.

## Установка и запуск

```
node js-art/server.js            # корень сайта по умолчанию: ./site, порт 5173
node js-art/server.js --root site --port 5173 --out css/js-art.css
```

- Сервер раздаёт статику из `--root` и при отдаче любого `.html` вставляет перед `</body>`
  `<script type="module" src="/__js-art/client/index.js"></script>`. Файлы на диске при этом не меняются.
- Слушает только `127.0.0.1`.
- Без сервера панель подключается вручную: `<script type="module" src="../js-art/client/index.js">`
  (при любом статическом сервере). Тогда «Сохранить» = скопировать CSS в буфер + скачать файл.

## Структура

```
js-art/
  package.json        {"type":"module"}, scripts: start, test; без зависимостей
  server.js           HTTP-сервер, инъекция панели, API сохранения
  lib/save.js         запись CSS/состояния, бэкапы, вставка <link> в HTML (чистые функции + fs)
  client/
    index.js          точка входа: ждёт DOM, собирает модули, восстанавливает state
    ui.js             панель в Shadow DOM: иконка, окно, разделы, контролы
    controls.js       описания контролов (какое свойство, единицы, диапазон, тип)
    picker.js         пипетка: подсветка под курсором, выбор, родитель/дочерний
    model.js          originals / current / undo-redo, применение правок
    css-writer.js     сериализация правок в CSS-текст
    color.js          парсинг/форматирование цветов, альфа
    selector.js       генерация CSS-селектора для элемента
    scan.js           сбор палитры: цветовые переменные :root, крупнейшие фоны
  test/*.test.js      node --test
  history/            бэкапы (в .gitignore)
  state.json          позиции ползунков
  README.md
```

`js-art/` лежит в корне репозитория, вне `site/`, поэтому в Docker-образ не попадает.

## Панель

- Shadow DOM — стили сайта и панели изолированы. Все z-index максимальные.
- **Свёрнута:** круглая иконка 44 px в правом нижнем углу; перетаскивается, позиция и состояние
  (свёрнута/развёрнута) хранятся в `localStorage` (обёрнуто в try/catch).
- **Развёрнута:** окно ~320 px, высота до 80vh со скроллом. При ширине < 560 px — нижняя шторка на всю ширину.
- Своя светлая/тёмная тема по `prefers-color-scheme`.
- Шапка: название, переключатель зоны **[Страница | Блок 🎯]**, кнопка свернуть.
- Разделы-аккордеоны: Цвета фона · Цвета текста · Типографика · Отступы · Размеры · Эффекты.
- Контрол: подпись, ползунок, числовое поле (или color-input + альфа-ползунок для цветов), кнопка ↺.
  Изменённый контрол помечен точкой; ↺ возвращает исходное значение.
- Подвал: «Отменить всё», «Сохранить» (с состоянием: сохранено / ошибка / есть изменения).
- Клавиши: Ctrl+Z / Ctrl+Shift+Z — undo/redo, Esc — выход из пипетки, затем свернуть.
- Элементы панели пипеткой не выбираются.

## Зона «Страница»

| Раздел | Контролы | Куда пишется |
|---|---|---|
| Цвета фона (палитра) | каждая цветовая custom property из `:root` (`--bg`, `--bg-2`, `--stage`, `--card`, `--ink`, `--accent`…): цвет + альфа — это и фоны, и цвета текста сайта, поэтому раздел называется «Палитра», если переменные найдены. Если цветовых переменных нет — до 5 крупнейших по площади фонов «Фон 1…5» | `:root{--bg:…}` / селекторы правил, задающих этот фон |
| Цвета текста | h1, h2, h3, h4, p, a, small: цвет + альфа (прозрачность текста) | `h1{color:…}` |
| Типографика | базовый размер (`html` font-size, %); для h1–h4, p: размер (×), межбуквенный (em), межстрочный | `h1{font-size:calc(… * k)}` |
| Отступы | вертикальные отступы секций (×), поля контейнера (×) | `section{padding-block:…}` |
| Размеры | масштаб изображений (`img`), иконок (`svg` не внутри img) | `zoom` |
| Эффекты | контраст, яркость, насыщенность страницы | `html{filter:…}` |

Цветовая переменная определяется так: значение переменной на `:root` парсится как цвет (`color.js`).
Подписи — имя переменной; для переменных темы значение берётся для текущей темы, а запись идёт в тот же
селектор, где переменная объявлена для текущей темы (`:root` или `:root[data-theme="dark"]`).

## Зона «Блок»

1. 🎯 → наведение подсвечивает элемент рамкой и подписью-селектором; клик выбирает (клик не уходит в сайт).
2. Кнопки ↑ (родитель) / ↓ (первый дочерний элемент) уточняют выбор.
3. Охват: «все такие» — селектор по классам/тегу с ближайшим предком-классом (`.srow h3`, `.case`);
   «только этот» — путь с `:nth-of-type` от ближайшего элемента с id или от `body`.
4. Контролы: фон + альфа, цвет текста + альфа, размер текста (×), межбуквенный, межстрочный,
   padding ×4 и margin ×4 (замок «все стороны»), ширина, высота (px; 0 = auto/исходное), скругление, gap,
   opacity, контраст, размер картинок и иконок внутри блока (`zoom`).

## Модель значений

- **Исходные значения** снимаются при старте и при выборе блока, с временно выключенным
  `<link>` на `js-art.css` и выключенным собственным `<style>` с правками (`sheet.disabled = true`).
- Правка = `{selector, property, value}`. Все правки живут в одном `<style id="js-art-live">` в `<head>`,
  его содержимое генерирует `css-writer.js` (тот же текст, что сохраняется в файл).
- **Размеры-множители:** контрол хранит коэффициент `k`. В CSS пишется `calc(<объявленное значение> * k)`,
  если объявленное значение нашлось в same-origin таблицах стилей (последнее подходящее по
  `el.matches(selectorText)` правило вне медиа-запросов или в сработавшем медиа-запросе), иначе
  `calc(<вычисленное px> * k)`. При `k = 1` правка удаляется.
- Значение, совпадающее с исходным, правкой не считается.
- Undo/redo — стек снимков набора правок (до 100 шагов).

## Сохранение

`POST /__js-art/save` с `{css, state}`:

1. если файл `--out` существует — копия в `js-art/history/YYYY-MM-DD_HH-mm-ss.css`;
2. запись `<root>/<out>` (заголовок-комментарий «generated by JS-Art» + правила);
3. запись `js-art/state.json`;
4. во все `.html` в корне `--root`, где нет маркера `<!-- js-art -->`, после последнего
   `<link rel="stylesheet">` в `<head>` вставляется `<!-- js-art --><link rel="stylesheet" href="<out>">`.
   Повторные сохранения HTML не трогают.

`GET /__js-art/state` возвращает `state.json` (или `{}`), панель восстанавливает ползунки.
Пустой набор правок сохраняет пустой (с комментарием) CSS — `<link>` остаётся безвредным.
Ошибки записи возвращаются с кодом 500 и текстом, панель показывает их в подвале.

Без сервера (`/__js-art/save` недоступен): CSS копируется в буфер и скачивается как `js-art.css`.

## Тестирование

- `node --test js-art/test` — `color.js`, `selector.js` (на минимальном DOM-подобном объекте),
  `css-writer.js`, `lib/save.js` (вставка `<link>`, идемпотентность, бэкап, во временной папке).
- Ручная проверка в браузере на портфолио: обе зоны, сохранение → перезагрузка → значения на месте,
  светлая/тёмная тема, ширина 375 px, отсутствие ошибок в консоли.

## Не входит

Правки под отдельные брейкпоинты, `:hover`/`:focus`-состояния, переписывание исходного `style.css`,
редактирование текста/контента, live-reload.
