# JS-Art

Инструмент арт-разработчика: панель поверх сайта, которая меняет цвета, типографику, отступы и размеры
в реальном времени и сохраняет результат прямо в файлы проекта. Код руками править не нужно.

Без зависимостей и сборки — нужен только Node.js 18+.

## Установка

Положите инструмент в корень проекта (рядом с папкой сайта) — клоном или копией папки:

```bash
git clone https://github.com/JohnaeroL/js-art.git js-art
```

Если проект сам в git, добавьте `js-art/history/` в его `.gitignore`.

## Запуск

```bash
node js-art/server.js
```

Откройте http://localhost:5173 — в правом нижнем углу появится круглая кнопка JS-Art.

| Флаг | По умолчанию | Что задаёт |
|---|---|---|
| `--root` | `site` | папка сайта (относительно текущей) |
| `--port` | `5173` | порт; сервер слушает только `127.0.0.1` |
| `--out` | `css/js-art.css` | куда сохранять CSS (относительно `--root`) |

Сервер раздаёт сайт и сам подставляет панель в HTML на лету — в файлы сайта панель не попадает.

## Панель

- **Кнопка** — открыть/свернуть; её можно перетащить, позиция запоминается.
- **Страница** — палитра (цветовые CSS-переменные `:root` или крупнейшие фоны), цвета текста по тегам,
  типографика (базовый размер, H1–H4, абзацы), отступы секций и поля страницы (`padding-inline` у `body`),
  размер изображений и иконок, контраст / яркость / насыщенность.
  Размер, интервалы и отступы секций меняются **относительно** каждого правила, которое их задаёт:
  «Абзац × 1.1» увеличит и мелкие подписи, и крупный лид на 10 %, сохранив иерархию
  (`p:is(.hero-lead) { font-size: calc(... * 1.1) }`). Inline-стили и `:hover` сайта при этом продолжают работать.
  Правки палитры пишутся в тот же селектор (и `@media`), где объявлена переменная, и не протекают в другую тему.
- **Шрифты** — раздел «Шрифт и начертание»: выбор из 30 бесплатных шрифтов Google Fonts (все с кириллицей),
  насыщенность 100–900, курсив и регистр. На странице отдельно для заголовков и основного текста, в «Блоке» — для выбранного элемента.
  Файлы шрифтов не хранятся в проекте: шрифт подгружается с fonts.googleapis.com, а в `js-art.css` первой строкой
  пишется `@import` только для выбранных шрифтов — нужен интернет и CSP сайта должен разрешать этот домен.
- **Блок** — «Выбрать», затем клик по элементу на сайте (Esc — отмена). ↑ / ↓ — родитель / дочерний элемент.
  «Все такие» правит все элементы с тем же селектором (`.srow h3`), «Только этот» — один элемент.
  «Положение»: сдвиг по X/Y (CSS `translate` — соседние блоки не двигаются) и `order` для детей flex/grid.
  Кнопка ✥ в панели блока включает режим «Двигать»: выбранный блок тянется мышью прямо на странице
  (клики по нему в этом режиме не срабатывают). Один жест — один шаг Ctrl+Z.
  Цвета и прозрачность, размер текста, интервалы, padding и margin по сторонам (замок — все стороны вместе),
  ширина, высота, скругление, gap, размер картинок и иконок внутри, непрозрачность, контраст.
- У каждого ползунка: поле для точного значения и ↺ — вернуть исходное значение из кода.
  Изменённые отмечены точкой, число правок видно у раздела.
- **Ctrl+Z / Ctrl+Shift+Z** — отмена / повтор (одно перетаскивание = один шаг). **Esc** — свернуть.
- Размеры пишутся множителем от исходного значения: `calc(clamp(3rem,10vw,9rem) * 1.2)` —
  «резиновые» значения остаются резиновыми.

## Сохранение

«Сохранить»:

1. записывает `<root>/css/js-art.css` — обычный читаемый CSS, сгруппированный по селекторам;
2. записывает `js-art/state.json` — положения ползунков, чтобы после перезагрузки всё было на месте;
3. перед перезаписью кладёт прошлую версию в `js-art/history/ДАТА_ВРЕМЯ.css` и `ДАТА_ВРЕМЯ.json` (состояние);
4. один раз добавляет в HTML-файлы сайта строку
   `<!-- js-art --><link rel="stylesheet" href="css/js-art.css" data-js-art>` после последнего stylesheet.

Сервер принимает запросы только с `localhost` / `127.0.0.1` и только JSON от своей же страницы —
другие сайты, открытые в браузере, записать в проект ничего не могут.

После этого сайт выглядит так же и без JS-Art (например, в Docker/nginx).

Без сервера панель можно подключить вручную: `<script type="module" src="/путь/к/js-art/client/index.js"></script>`.
Тогда «Сохранить» копирует CSS в буфер и скачивает файл `js-art.css`.

## Как откатить

- Ползунок — ↺; всё — «Сбросить всё» (Ctrl+Z вернёт).
- Сохранённое — панель восстанавливает правки из `js-art/state.json`, поэтому откатывайте пару файлов:
  - убрать всё: удалите `css/js-art.css`, `js-art/state.json` и строку с `<!-- js-art -->` в HTML;
  - вернуть прошлую версию: скопируйте `history/ДАТА_ВРЕМЯ.css` в `css/js-art.css`
    и `history/ДАТА_ВРЕМЯ.json` в `js-art/state.json`.

## Ограничения

- Правка действует на всех ширинах экрана — правок под отдельный брейкпоинт нет.
- В режиме «Блок» свойства пишутся с `!important`, поэтому изменённое свойство перекрывает и `:hover`-правило сайта для него.
- Исходный `style.css` не переписывается — все изменения лежат отдельным слоем `js-art.css`.
