# JS-Art

Инструмент арт-разработчика: панель поверх сайта, которая меняет цвета, типографику, отступы и размеры
в реальном времени и сохраняет результат прямо в файлы проекта. Код руками править не нужно.

Без зависимостей и сборки — нужен только Node.js 18+.

## Установка

Положите инструмент в корень проекта (рядом с папкой сайта) — клоном или копией папки:

```bash
git clone https://github.com/JohnaeroL/js-art.git js-art
```

Если проект сам в git, добавьте `js-art/history/` в его `.gitignore`.

## Запуск

```bash
node js-art/server.js
```

Откройте http://localhost:5173 — в правом нижнем углу появится круглая кнопка JS-Art.

Без терминала: двойной клик по `js-art/start-js-art.bat` (можно вынести ярлык на рабочий стол) — запускает сервер
и открывает сайт в браузере. Параметры передаются так же: `start-js-art.bat --root www --open /about.html`.

| Флаг | По умолчанию | Что задаёт |
|---|---|---|
| `--root` | `site` | папка сайта (относительно текущей) |
| `--port` | `5173` | порт; сервер слушает только `127.0.0.1` |
| `--out` | `css/js-art.css` | куда сохранять CSS (относительно `--root`) |
| `--open [путь]` | — | открыть браузер на сайте (или на странице `путь`, например `/about.html`) |

Сервер раздаёт сайт и сам подставляет панель в HTML на лету — в файлы сайта панель не попадает.

## Панель

- **Кнопка** — открыть/свернуть; её можно перетащить, позиция запоминается. Пока панель открыта, кнопка скрыта;
  при сворачивании она появляется в углу, где была панель. Кнопка перетаскивается независимо от панели.
- **Шапка** — логотип JS-Art, переключатель темы панели (☀ / ☾: светлая или тёмная; по умолчанию следует системе,
  выбор запоминается), отмена / повтор, свернуть. Саму панель можно тянуть за шапку; позиция запоминается,
  и панель не уходит за край окна. На телефонной ширине (до 560px) панель — шторка снизу, её не тянут.
  Кнопка ↻ — проверка обновлений с GitHub (см. «Обновление» ниже).
- **Страница** — палитра (цветовые CSS-переменные `:root` или крупнейшие фоны), цвета текста по тегам,
  типографика (базовый размер, H1–H4, абзацы), отступы секций и поля страницы (`padding-inline` у `body`),
  размер изображений и иконок, контраст / яркость / насыщенность.
  Размер, интервалы и отступы секций меняются **относительно** каждого правила, которое их задаёт:
  «Абзац × 1.1» увеличит и мелкие подписи, и крупный лид на 10 %, сохранив иерархию
  (`p:is(.hero-lead) { font-size: calc(... * 1.1) }`). Inline-стили и `:hover` сайта при этом продолжают работать.
  Правки палитры пишутся в тот же селектор (и `@media`), где объявлена переменная, и не протекают в другую тему.
  Группа «Шрифт и начертание» — шрифт, насыщенность, курсив и регистр для заголовков и основного текста.
- **Шрифты** — раздел «Шрифт и начертание»: выбор из 30 бесплатных шрифтов Google Fonts (все с кириллицей),
  насыщенность 100–900, курсив и регистр. На странице отдельно для заголовков и основного текста, в «Блоке» — для выбранного элемента.
  Выпадающий список показывает каждый шрифт его же начертанием на русском и английском, поэтому выбирать можно «на глаз»
  (примеры подгружаются при первом открытии списка, нужен интернет; на шрифты самого сайта они не влияют).
  При «Сохранить» выбранные шрифты скачиваются **в проект**: файлы woff2 (latin + cyrillic) — в `<root>/fonts/js-art/`,
  а `@font-face` — прямо в `js-art.css`. Сайт после этого не зависит от Google Fonts и работает офлайн; все шрифты каталога
  свободные (SIL OFL / Apache). Если скачать не удалось (нет сети), в `js-art.css` остаётся `@import` с Google Fonts
  и панель сообщает об этом.
- **Экран** — переключатель «Все экраны / Десктоп / Мобильный» под вкладками. «Все» пишет правки как есть;
  «Десктоп» — внутрь `@media (min-width: 768px)`, «Мобильный» — внутрь `@media (max-width: 767px)`.
  Блоки с `@media` пишутся в `js-art.css` после обычных, поэтому правка для экрана перекрывает общую.
  Предпросмотр зависит от ширины окна браузера: кнопка с телефоном рядом с переключателем открывает сайт в узком окне
  (420px) сразу в режиме «Мобильный»; правки двух окон общие, сохранять можно из любого. Либо сузьте окно (или F12 → Ctrl+Shift+M),
  панель подсказывает, если ширина не подходит. Исходные значения ползунков берутся из кода сайта на текущей ширине;
  правки «Всех экранов» в мобильном режиме в них не учитываются, и мобильные правки перекрывают их целиком.
- **Тема сайта** — переключатель «Все темы / Светлая / Тёмная»: правки применяются только к выбранной теме.
  Способ переключения тем сайт определяется сам и правка пишется под него:
  `<html data-theme="dark">` → `:root[data-theme="dark"] .card {…}`, класс `dark` на `<html>` → `:root.dark .card {…}`,
  иначе `@media (prefers-color-scheme: dark) {…}`. «Светлая» — это «не тёмная», поэтому сайт, у которого оформлена только
  тёмная тема, тоже работает. Для атрибута и класса панель сама переключает тему страницы (при «Все темы» возвращает как было),
  для `prefers-color-scheme` тему задаёт система — панель подскажет, если она не совпадает. Палитра (CSS-переменные)
  и так пишется в ту тему, где переменная объявлена. Экран и тема сочетаются.
- **Блок** — «Выбрать», затем клик по элементу на сайте (Esc — отмена). ↑ / ↓ — родитель / дочерний элемент.
  «Все такие» правит все элементы с тем же селектором (`.srow h3`), «Только этот» — один элемент.
  «Тень»: смещение по X/Y, размытие, растяжение, цвет с прозрачностью, снаружи / внутри (`box-shadow`).
  Нетронутые параметры остаются как в коде сайта; из нескольких теней сайта берётся первая.
  «Выравнивание»: блок слева / по центру / справа (и сверху / по центру / снизу) внутри родителя, выравнивание текста,
  а у flex/grid-контейнера ещё и содержимое по осям. Запись зависит от родителя: grid — `justify-self`/`align-self`,
  flex — `align-self` и автоотступы, обычный поток — автоотступы (блок на всю ширину сначала сжимается по содержимому,
  строчный элемент, например картинка, становится `display: block`).
  «Положение»: сдвиг по X/Y (CSS `translate` — соседние блоки не двигаются) и `order` для детей flex/grid.
  Если у блока уже был свой `translate`, он заменяется. Сдвиг по одной оси пишет вторую как `0`.
  Кнопка ✥ в панели блока включает режим «Двигать»: выбранный блок тянется мышью прямо на странице
  (клики по нему в этом режиме не срабатывают). Один жест — один шаг Ctrl+Z.
  «Текст»: у блока без вложенных элементов (заголовок, абзац, кнопка, ссылка) можно переписать сам текст.
  Правка видна сразу; при «Сохранить» новый текст записывается в HTML страницы (прошлая версия — в `history/ДАТА_ВРЕМЯ_имя.html`),
  а не в CSS. Если сервер не может однозначно найти текст в HTML (он собирается скриптом, стоит в другом файле),
  правка остаётся в панели и сохранение сообщает об этом.
  Цвета и прозрачность, размер текста, шрифт, интервалы, padding и margin по сторонам (замок — все стороны вместе),
  ширина, высота, скругление, gap, размер картинок и иконок внутри, непрозрачность, контраст.
  Кнопка «Экран» и «Тема сайта» действуют и здесь: выбор «Мобильный» + «Тёмная» пишет правку в обе медиа-условия.
- У каждого ползунка: поле для точного значения и ↺ — вернуть исходное значение из кода.
  Изменённые отмечены точкой, число правок видно у раздела.
- **Ctrl+Z / Ctrl+Shift+Z** — отмена / повтор (одно перетаскивание = один шаг). **Esc** — свернуть.
- Размеры пишутся множителем от исходного значения: `calc(clamp(3rem,10vw,9rem) * 1.2)` —
  «резиновые» значения остаются резиновыми.
- **«Сбросить всё»** — с подтверждением: первый клик меняет кнопку на «Точно сбросить?» на 3 секунды, второй сбрасывает
  все несохранённые правки (Ctrl+Z вернёт).

## Сохранение

«Сохранить»:

1. записывает `<root>/css/js-art.css` — обычный читаемый CSS, сгруппированный по селекторам;
   в начале — `@font-face` выбранных шрифтов (см. ниже); правки экранов «Десктоп» и «Мобильный» идут в `@media` в конце файла;
2. записывает `js-art/state.json` — положения ползунков, чтобы после перезагрузки всё было на месте;
3. перед перезаписью кладёт прошлую версию в `js-art/history/ДАТА_ВРЕМЯ.css` и `ДАТА_ВРЕМЯ.json` (состояние);
4. если изменён текст блоков — записывает его в HTML страницы, прошлую версию страницы кладёт в
   `js-art/history/ДАТА_ВРЕМЯ_имя.html`; текст, который не удалось однозначно найти, остаётся в панели с причиной;
5. скачивает выбранные шрифты в `<root>/fonts/js-art/` (woff2, latin и cyrillic) — сайт работает без Google Fonts;
   если сеть недоступна, в `js-art.css` остаётся `@import` Google Fonts и панель сообщает об этом;
6. один раз добавляет в HTML-файлы сайта строку
   `<!-- js-art --><link rel="stylesheet" href="css/js-art.css" data-js-art>` после последнего stylesheet.

Текст сохраняется только при запуске через сервер; без него панель копирует CSS в буфер и скачивает файл, а текст не сохраняется.

Сервер принимает запросы только с `localhost` / `127.0.0.1` и только JSON от своей же страницы —
другие сайты, открытые в браузере, записать в проект ничего не могут.

После этого сайт выглядит так же и без JS-Art (например, в Docker/nginx).

Без сервера панель можно подключить вручную: `<script type="module" src="/путь/к/js-art/client/index.js"></script>`.
Тогда «Сохранить» копирует CSS в буфер и скачивает файл `js-art.css`.

## Как откатить

- Ползунок — ↺; всё — «Сбросить всё» (с подтверждением; Ctrl+Z вернёт).
- Шрифты — удалите `<root>/fonts/js-art/` вместе с `css/js-art.css`; если шрифты не выбраны, сохранение папку не создаёт.
- Текст на странице — в `js-art/history/` лежат прошлые версии HTML; скопируйте нужную обратно поверх страницы.
- Сохранённое — панель восстанавливает правки из `js-art/state.json`, поэтому откатывайте пару файлов:
  - убрать всё: удалите `css/js-art.css`, `js-art/state.json` и строку с `<!-- js-art -->` в HTML;
  - вернуть прошлую версию: скопируйте `history/ДАТА_ВРЕМЯ.css` в `css/js-art.css`
    и `history/ДАТА_ВРЕМЯ.json` в `js-art/state.json`.

## Ограничения

- Экраны делятся по одной границе, 768px: «Десктоп» и «Мобильный». Предпросмотр зависит от ширины окна браузера.
- Текст редактируется только у элементов без вложенных тегов; абзац с `<b>` внутри — через дочерний элемент.
- Текст ищется в HTML по содержимому. Если на странице он собирается скриптом или отличается от исходника,
  правка не запишется, а панель сообщит причину — тогда редактируйте исходник вручную.
- Шрифты для превью в списке берутся с fonts.googleapis.com (нужен интернет при открытии списка);
  на сохранённый сайт это не влияет.
- Окно «узкого» режима и основная панель синхронизируются через `BroadcastChannel` — только в одном браузере и одном профиле.
- В режиме «Блок» свойства пишутся с `!important`, поэтому изменённое свойство перекрывает и `:hover`-правило сайта для него.
- Исходный `style.css` не переписывается — все изменения лежат отдельным слоем `js-art.css`.

## Обновление

Плагин можно обновлять с GitHub прямо из панели. Проверка и обновление происходят **только по нажатию** кнопки ↻ в шапке;
без нажатия плагин в сеть не ходит.

1. Первое нажатие ↻ — `git fetch` и сравнение с веткой `origin/main`. Если есть новые коммиты, кнопка краснеет,
   в статусе — их число и хеш версии. Через 8 секунд подтверждение сбрасывается.
2. Второе нажатие — обновление: `git merge --ff-only`. Только перемотка вперёд; ничего не перезаписывается и не сбрасывается.
3. Сервер перезапускается сам, если запущен через `start-js-art.bat`. Иначе перезапустите его вручную и обновите страницу.

Обновление не делается и сообщает причину, если:
- в папке `js-art` есть несохранённые изменения (`git status`);
- есть локальные коммиты, которых нет на GitHub;
- папка установлена не клоном git (тогда переустановите через `git clone`);
- git не установлен или нет связи с GitHub.

Требования: установленный git в `PATH` и клон из репозитория (как в «Установке»). Обновляется только папка плагина:
сайт, `css/js-art.css`, `state.json` и `history/` не трогаются.

Важно: обновление запускает код, который приходит из настроенного remote (по умолчанию GitHub). Обновляйте только
из репозитория, которому доверяете.

## Логотип

Файлы в `js-art/assets/`: `logo-wordmark.svg` (светлая тема), `logo-wordmark-dark.svg` (тёмная), `logo.svg` (значок),
`favicon.svg`. Цвета — фиолетовый (`#6d5efc` / `#8b7fff`) и белый; «JS» — в шрифте интерфейса, «Art» — фиолетовым.
В шапке панели тот же логотип; цвет «JS-» берётся из темы панели.

## Тесты

```bash
cd js-art && node --test
```

104 теста: разбор CSS, сохранение и откат, текст в HTML, шрифты (каталог, загрузка, локализация), выравнивание,
тени, темы, экраны, аргументы запуска, обновления (git, маршруты сервера, тексты статусов).
